# AI智能医疗导诊系统
毕业设计 | SpringBoot + Vue3 + LLM大模型导诊平台

## 项目简介
本系统是基于SpringBoot + Vue3 + MySQL搭建的医疗导诊平台，集成大模型实现症状分诊。

## ✨功能模块
1. 用户端：症状输入、AI初步导诊分诊
2. 管理后台：患者信息、知识库管理
3. RAG模块：读取医疗知识库，辅助大模型回答，减少幻觉

## 🛠技术栈
后端：SpringBoot、MyBatis、MySQL
前端：Vue3
AI：大模型 + RAG检索增强
工具：Postman、JMeter
